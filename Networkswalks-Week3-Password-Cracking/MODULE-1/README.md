Module 1: PDF Hash Extraction Using John the Ripper (JtR)

Objective

To extract the password hash from a password-protected PDF file using John the Ripper (JtR).

Tool Used

- Kali Linux
- John the Ripper (JtR)

Activities Performed

1. Check John the Ripper Version

Verified the installed John the Ripper version in Kali Linux.

2. PDF Hash Extraction

Extracted the password hash from the password-protected PDF file using the PDF hash extraction tool.

3. Success Result

Successfully extracted the PDF password hash and saved it in "hash1.txt" for further password-cracking analysis.
