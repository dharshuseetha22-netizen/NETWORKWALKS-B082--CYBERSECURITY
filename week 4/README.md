🚀 **Week 4 of My Cybersecurity Internship at NETWORKWALKS!**

🔐 **Black-Box Web Application Security Assessment – Mediroza General Hospital**

This week's project introduced me to the methodology of black-box web application penetration testing, focusing on identifying potential security weaknesses and understanding web application security.

Throughout this project, I explored four key milestones:

🎯 **M1 – Reconnaissance**
- Website reconnaissance using cURL
- HTTP response and header inspection
- Robots.txt and sitemap analysis
- SSL certificate inspection
- Web technology identification

🔓 **M2 – PDF Encryption Audit**
- PDF encryption analysis
- AES-256 encryption concepts
- Password security assessment using authorised test files

🗄️ **M3 – Database Security Assessment**
- SQLite database security
- Analysis of fictional employee and shareholder records
- Linux file permission assessment

📄 **M4 – Security Assessment Report**
- Technical findings documentation
- Risk assessment and severity classification
- Security recommendations and remediation strategies

🛠️ **Tools & Technologies:** Kali Linux, Nmap, cURL, qpdf, SQLite and Python.

**My biggest takeaway:** Effective cybersecurity is not just about finding vulnerabilities; it is about understanding security weaknesses, evaluating risks and recommending practical solutions.
